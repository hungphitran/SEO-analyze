## Intentionally Hidden Paid-Only Routes (Keep Hidden in `FREE_SOURCES_ONLY=true`)

Defined in `src/shared/free-sources-visibility.ts` (`PAID_ONLY_PROJECT_ROUTE_SEGMENTS`):

- `keywords`, `saved`, `domain`, `backlinks`, `ai-visibility`, `prompt-explorer`, `local-seo`, `brand-lookup`
- Dashboard tab: `backlinks`
- Onboarding steps: `competitor`, `keywords`

These routes remain guarded and redirected in `FREE_SOURCES_ONLY=true`. New free-only features (Keyword Opportunities, GEO Evidence, Backlink Samples, Crawl Diff / Internal Links) will use new free-capable routes or extend existing free-capable tabs without re-enabling DataForSEO routes.
